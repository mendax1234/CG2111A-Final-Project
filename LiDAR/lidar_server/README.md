# Instructions
1. These are the files used for SLAM mapping and TLS server setup.
2. Note that all libraries other than networking has been deleted to prevent bloat. 
3. Remaining files here serve as a guide on how to setup TLS communication between RPi and PC, they do not work out of the box and require setting up the virtual environment and installing the libraries which are not provided here.
4. Server key, cert, csr and signing perm goes into SlamLab -> nodes, TLS_node_data.
